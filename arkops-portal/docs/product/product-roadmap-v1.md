## V1.0 — 运营核心闭环（当前 + 补全）

> **目标**：让商家能在 AllMall 中完成 80% 的日常运营，无需频繁切换到各平台后台。

### 已有功能（不重复开发）
| 功能 | 覆盖度 | 状态 |
|------|:--:|:--:|
| 店铺连接与授权管理 | 90% | ✅ 已实现 |
| 商品管理 SPU+铺货 | 85% | ✅ 已实现（P0/P1/P2 全部完成） |
| 订单履约与异常处理 | 80% | ✅ 已实现 |
| Inbox 统一待办中心 | 90% | ✅ 已实现 |
| Dashboard 经营总览 | 70% | ✅ 已实现 |
| Agent 系统（15 Agent） | 80% | ✅ 已实现 |
| 计费订阅体系 | 70% | ✅ 已实现 |
| 成员管理与权限 | 80% | ✅ 已实现 |

### 新增交付
| 编号 | 模块 | 需求来源 | 关键功能 |
|:--:|------|----------|----------|
| V1.0-1 | **客服消息系统** | P0 缺口 — 电商日活最高功能 | 会话列表、消息气泡、快捷回复、转人工、会话标签、搜索筛选 |
| V1.0-2 | **评价管理系统** | P0 缺口 — 差评直接影响转化 | 评价列表（按店铺/评分/时间筛选）、回复编辑器、回复模板、差评预警标签 |

### 验收标准
- 客服：支持多店铺会话聚合，按店铺/未回复/已回复筛选，快捷回复模板 5+ 条，一键标记已处理
- 评价：支持按评分（1-5星）/店铺/日期筛选，内联回复编辑器，模板库 5+ 条，差评自动标记预警

## V1.1 — 增长引擎：营销与库存

> **目标**：从"日常运营"升级到"主动增长"，覆盖商家的营销和库存决策场景。

### 新增交付
| 编号 | 模块 | 关键功能 |
|:--:|------|----------|
| V1.1-1 | **促销活动管理** | 活动创建（时间/店铺/折扣类型/预算）、活动日历（日/周/月视图）、活动效果看板（GMV/订单/ROI 环比）、优惠券模板管理 |
| V1.1-2 | **库存管理升级** | 补货建议（基于 7/14/30 天销量预测）、库间调拨建议、安全库存设置、库存周转率看板 |
| V1.1-3 | **广告投放可视化** | 广告账户总览（花费/展示/点击/转化）、分计划对比表、创意素材预览、ROI 趋势图 |

### 验收标准
- 促销：支持满减/折扣/秒杀三种活动类型，日历拖拽调整时间，活动期 vs 非活动期效果对比
- 库存：补货建议算力基于销量均值和安全库存公式，调拨建议显示源/目标库存差异
- 广告：4 维度 KPI 卡片（花费/ROI/CPC/转化率），分计划数据表格，广告 Agent 策略联动

---

## V1.2 — 数据驱动：报表与分析

> **目标**：让不同角色的用户都能看到自己关心的数据，支持数据导出和分享。

### 新增交付
| 编号 | 模块 | 关键功能 |
|:--:|------|----------|
| V1.2-1 | **可配置 Dashboard** | Widget 拖拽布局、6+ Widget 类型（KPI卡片/趋势图/排行榜/饼图/店铺对比/Agent成果）、保存多视图、按角色默认视图 |
| V1.2-2 | **运营报表中心** | 日报/周报/月报自动生成、报表模板（GMV报告/广告报告/客服报告/库存报告）、定时邮件发送、PDF 导出 |
| V1.2-3 | **数据导出** | 全表 CSV 导出、图表 PNG 导出、日期范围选择、分店铺导出 |

### 验收标准
- Dashboard：支持 3+ 个自定义视图，Widget 拖拽排序，Owner/Operator 不同默认视图
- 报表：4 种报告模板，PDF 导出含图表，定时发送配置
- 导出：所有数据表格均有导出按钮，支持全量/筛选后导出

## V1.3 — 深度运营：直播与内容

> **目标**：补全直播电商和内容运营两大增量场景。

### 新增交付
| 编号 | 模块 | 关键功能 |
|:--:|------|----------|
| V1.3-1 | **直播运营面板** | 直播排期日历、直播数据看板（观看/互动/成交）、话术库管理、场次对比分析、开播提醒 |
| V1.3-2 | **素材管理中心** | 图片/视频素材库、按商品/店铺/类型分类、AI 素材生成（主图/详情页/ Banner）、素材使用追踪 |
| V1.3-3 | **内容排期** | 商品内容发布日历（标题/描述/主图更新）、批量内容模板、发布审核流程 |

### 验收标准
- 直播：排期日历支持新增/编辑/取消，数据看板含至少 6 项指标，话术库 20+ 条
- 素材：素材上传/预览/删除，AI 生成入口，素材-商品关联
- 内容：排期日历与商品管理联动，批量模板支持变量替换（{name}/{price}等）

## V1.4 — 企业级：协作与开放

> **目标**：满足品牌团队和代运营机构的协作需求，开放平台能力。

### 新增交付
| 编号 | 模块 | 关键功能 |
|:--:|------|----------|
| V1.4-1 | **团队协作** | 站内消息（评论/审批/通知）、任务分配与追踪、操作日志 @人员、团队动态 Feed |
| V1.4-2 | **API 与 Webhook** | OpenAPI 文档、API Key 管理、Webhook 配置（事件订阅）、调用量监控、SDK（可选） |
| V1.4-3 | **自定义工作流** | 可视化工作流编辑器（拖拽节点）、条件分支、定时/事件触发、模板市场 |
| V1.4-4 | **引导升级** | 交互式产品导览（Tooltip 流程）、视频教程嵌入、ROI 计算器、智能推荐「下一步」 |

### 验收标准
- 协作：消息通知中心，任务可分配/转交/标记完成，Feed 实时刷新
- API：完整的 RESTful 接口文档，5 种 Webhook 事件类型，调用频率限制
- 工作流：至少 5 个预置模板，编辑器支持 3 种节点类型（触发/条件/动作）
- 引导：3 条交互式导览路径（新手/运营/管理），ROI 计算器可交互
